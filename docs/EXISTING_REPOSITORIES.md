# Supporting work: promotion policy

[Portfolio](../README.md)

Earlier repository names recorded in the portfolio history include `aston-fitness-project`, `BasicPHP1`, `assignment2`, `my-first-website` and `my-first-website1`. They are not featured or linked as validated applications in this release. Their source, originality, current visibility and run paths were outside this two-repository release audit.

No project should be ranked from its name alone. Before promotion, inspect its actual source, establish attribution (especially coursework or team work), reproduce setup and tests, review private data and dependencies, and state completed behavior and limitations. Similar website iterations need a clear reason to feature both.

An independently completed local project may be described accurately only after validation. A public link requires an existing suitable public repository; do not invent a URL or publish a private project merely to fill the portfolio.
