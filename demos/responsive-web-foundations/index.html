Core principles

Designed from the content out

The layout changes only where the content needs more room, keeping the experience understandable at every width.

01

Mobile first

The base design fits small screens before wider arrangements are introduced.

02

Flexible by default

Fluid widths, wrapping navigation, and scalable type avoid rigid device assumptions.

03

Accessible throughout

Semantic landmarks, visible focus, and reduced motion support different ways of browsing.

Layout examples

A responsive toolkit

  • FlexboxAligns navigation and actions while allowing them to wrap.
  • CSS GridCreates balanced cards without fixed column widths.
  • Fluid sizingUses relative units and clamp() for comfortable reading.
  • Media queriesAdd layout enhancements when space becomes available.
