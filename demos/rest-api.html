Exercise the REST contract in the browser

An interactive console over the same service semantics as the Python module: validation rules, response codes, and a replaceable repository boundary. The browser demo uses an in-memory adapter; the real code targets the same protocol over PostgreSQL.

Simulation note. No HTTP server or PostgreSQL is used here. Responses are produced locally by a faithful translation of ItemService.
